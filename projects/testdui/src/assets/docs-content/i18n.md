## 概述

`i18n`（`src/i18n/dui`）不是一个导出 TypeScript 符号的编译入口，而是随 `@dotos/dui` 一起发布的**多语言静态翻译资源目录**（内置 `zh_CN.json`、`en_US.json` 等多国语言包），供 `@dotos/dui/translator` 的 `TranslationService.addTranslationFolder()` 在运行时按需异步加载。

## 核心模块与职责

| 资源路径 | 对应模块 | 职责说明 |
| --- | --- | --- |
| `i18n/dui/zh_CN.json` | 通用组件中文语言包 | 提供表格、分页、卡片视图、表单校验、剪贴板、查询构建器等内置组件的简体中文文案 |
| `i18n/dui/en_US.json` | 通用组件英文语言包 | 提供上述所有内置组件的英文文案 |
| `i18n/dock-layout/*.json` | 停靠窗口语言包 | 提供 `container/dock-layout` 窗口最大化、最小化、关闭与拆分提示文案 |

## 架构与设计模式

- **按模块命名空间分片加载**：当业务模块（如 `CardViewModule`、`DockLayoutModule`）被实例化时，会调用 `translationService.addTranslationFolder('dui', 'i18n')`，自动通过 `HttpClient` 请求 `/i18n/dui/<lang>.json` 并合并到全局字典中。

## 典型用法与最佳实践

在消费方宿主应用的 `angular.json` 中，请将 `@dotos/dui` 的 `i18n` 目录映射至构建产物的 `/i18n` 路径下，确保运行时 HTTP 请求能够命中静态 JSON 文件：

```json
{
  "assets": [
    "src/assets",
    {
      "glob": "**/*",
      "input": "node_modules/@dotos/dui/i18n",
      "output": "/i18n/"
    }
  ]
}
```
