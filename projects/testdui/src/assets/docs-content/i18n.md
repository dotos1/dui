## 概述

`i18n` 不是一个可导入的 TypeScript 模块，而是随库一起发布的**翻译资源目录**（中/英文 JSON 文件），供 `translator` 模块的 `TranslationService.addTranslationFolder()` 在运行时按需加载。

## 说明

如果你的应用引入了库内会调用 `addTranslationFolder('dui', 'i18n')` 之类逻辑的模块（例如 `form`、`container/dock-layout`、`common/keyboard` 等），需要确保这份资源目录（仓库根目录下的 `src/i18n/dui`）被拷贝进你应用的构建产物，否则对应的翻译文案会请求失败，页面上会显示原始的翻译 key 而不是文案。
