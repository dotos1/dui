## 概述

`base` 是整个 DUI 组件库最底层的运行时基础设施，不包含任何 UI 组件，只提供其他所有模块都会间接依赖的通用工具：事件发射器（`AngularEventEmitter`）、基类（`Base`/`DuiBase`）、DOM 操作辅助（`DomElements`）、观察者模式实现（`Observer`）等。

## 何时使用

绝大多数情况下你**不需要**直接从 `@dotos/dui/base` 导入任何东西——它是被库内其他模块在内部使用的基础层。只有在你需要扩展/自定义 DUI 的基础行为（例如实现一个自定义的事件发射器，或复用它的对象工具函数）时才需要直接接触这一层。
